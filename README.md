# 异星日志

莫比斯式科幻插画个人博客。当前使用**完整远景与石碑近景分镜切换**，配合带阻尼的鼠标跟随和可反向的短转场，保留原画细节。

## 本地运行

Node 24.13.x，依赖沿用原锁文件。

```sh
npm ci
npm run dev
```

预览：http://127.0.0.1:4321/

## 体验

- 首屏为原始完整远景。鼠标移动带动画面轻微平移，标题和导航固定；离开场景自然回中，悬停路灯和蓄力时暂停跟随。
- 向下滚动或点击「02 观测站」「走近石碑」，通过 440ms 淡出 / 换景 / 淡入进入近景；反向滚动从当前进度返回。只有一幅主画面可见，不模拟中间视角。
- 近景长按约 1.1 秒：圆环、碑文与光点响应；提前松手、失焦或滚动可以取消。蓄满后碑文亮起，约一秒后切回远景，路径、三盏灯和星图依次响应。唤醒后仍可使用阶段入口重新查看近景。
- 远景悬停路灯预览文章，点击进入分类；手机有独立入口。滚到底展开场景内日志列表。
- 正文采用顶部插画横幅、下方通栏 HTML 阅读区与目录。支持独立文章地址、选择文字、阅读进度、相邻文章、关闭返回和浏览器前进/后退。
- 导航保留文章、归档、关于和搜索。减少动态效果模式保留直接切换与键盘操作。
