# 异星日志

莫比斯式科幻插画个人博客。首页现已接入真实透视相机和独立深度的插画网格，具有可取消的蓄力、分阶段唤醒、路灯分类和连续阅读转场。

## 本地运行

Node 24.13.x；依赖保持原有精确版本与 `package-lock.json`。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4321/ 。运行 `npm run check`、`npm test`、`npm run build` 完成类型检查、状态机测试与静态构建。

## 体验方式

- 移动鼠标：云、星球、地形和前景按不同深度产生有阻尼的视差。
- 向下滚动：依次远望、靠近观测站、翻开场景内的最近日志；桌面行程约 2.8 屏，手机约 2.4 屏。滚到底仍保留完整场景，反向滚动连续返回；底部阶段入口可直接前往。
- 长按石碑约 1.1 秒：圆环、纹路和粒子同时蓄力，松手即可取消。完成后，地表能量波、三盏路灯、环境与星图依次响应。每次访问只能完成一次，刷新可重新体验。
- 悬停路灯预览文章，点击打开对应分类。手机提供单独的分类和长按入口。
- 打开文章后，场景收成顶部横幅，通栏阅读区呈现 HTML 正文与右侧目录；手机目录可展开。返回时收回阅读区并恢复之前的场景、滚动位置与分类。支持浏览器前进、后退；刷新独立文章地址采用相同的通栏布局。
- 导航提供文章、归档、关于和搜索；文章也可通过 `/journal/<slug>/` 独立访问。
