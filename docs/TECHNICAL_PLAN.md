# 异星日志：当前技术实现

更新：2026-11-04。本文描述已经接入的实现，未完成的能力列在末尾。视觉基准仍是 `design/references/`，没有以程序化低多边形场景替换精细插画。

## 技术与入口

沿用 Astro 7、React 19、Three.js / React Three Fiber 9、GSAP 3 / ScrollTrigger、Zustand 和 TypeScript，精确版本见 `package.json` 与原锁文件；未新增应用依赖。

首页 Astro 页面挂载 `JournalApp.tsx`。`IllustratedWorld.tsx` 提供海报、HTML 热点和延后加载的 `LayeredWorld.tsx`。正文来自同一份 Markdown：构建为独立 HTML 页面以及供阅读面板使用的 JSON。

## 场景资产与空间

`layer-data.ts` 以原图 1672×941 的像素坐标定义轮廓和深度，用 ShapeGeometry 截取原画。当前有天空、星球与星环、两组云、岛屿、后方岩壁、观测站、望远镜、天线、石碑、人物、围巾、三盏灯、树与前景。

已实际完成并接入三个补画资产：

| 文件 | 用途 |
| --- | --- |
| `public/images/layers/sky-clean.png` | 移除岛屿、星球和主体后的天空、云海远景；填补景层移动后露出的背景 |
| `public/images/layers/island-clean.png` | 移除观测站、石碑、人物与灯的干净地形，补出背后的草地和天空 |
| `public/images/layers/planet-cutout.png` | RGBA 星球与完整星环，补画被遮挡的表面，避免环边缺口和原图物件重影 |

原始细节仍取自 `public/images/observatory-world.png`。资产由内置 image_gen 编辑，来源、用途和完整提示词保存在相邻 `manifest.json`。几何轮廓承担其余物件的独立分层；它们不是完整三维实体。

各网格位于不同 Z 深度。初始尺寸按相机距离校正，使原画坐标对齐；PerspectiveCamera 的运动产生真实投影变化与深度遮挡。移动范围受限，不允许绕到插画的背面。手机重新安排画面比例，保证石碑、人物和三盏灯可见，并保留清楚的 HTML 入口。

## 动画的唯一控制来源

| 参数/对象 | 控制者 |
| --- | --- |
| 指针目标 | Pointer Events 写 `pointerX/Y`，渲染循环阻尼收敛 |
| 滚动目标 | SceneJourney 的单一 ScrollTrigger 时间线写 `scrollProgress`，按实际场景高度计算结束位置，原生滚动可逆 |
| 分类与阅读镜头偏移 | 单一可中断 GSAP tween 写 `focusX/focusZoom` |
| 蓄力 | 单一 charge tween；取消与立即重试会替换之前的 tween |
| 唤醒阶段 | 单一 GSAP timeline 写石碑、波半径、三灯、环境响应和星图值 |
| 最终相机位置、材质 uniform、热点投影 | R3F `useFrame` |
| 围巾/植物摆动、粒子吸引 | shader 时间和 uniform |
| 阅读面板 | GSAP 控制 clip-path / opacity，关闭从当前状态收回 |

逐帧参数存在 `motion-runtime.ts` 的可变对象中，不用 React state 驱动相机、粒子或材质。Zustand 的纯状态机只处理 idle / charging / awakening / awake 和离散导航事件。

## 交互细节

1. **探索与靠近**：阻尼视差；原生滚动在同一视口内经历远望、靠近、日志三个阶段，桌面行程约 2.8 个视口高度，手机约 2.4 个。标题、观测站提示、场景内日志卡片共用一个可逆时间线。相机先沿路径靠近，再在阅读入口处轻微收敛。滚动末尾仍留在完整场景，没有独立的底部文章区。底部阶段导航可以直接前往，快速反向会连续接续。
2. **蓄力**：pointer capture、约 1.1 秒、圆环进度、石碑扫描纹与粒子聚集；pointerup、pointercancel、lostpointercapture、blur、页面隐藏均取消。取消 tween 与再次蓄力不会竞争。
3. **唤醒**：石碑亮起 → 纹理地表坐标中的能量波扩散 → 阅读/实践/笔记三灯依次点亮并照亮局部地面 → 云和植物加强轻微运动 → 天空星图显现。此演出约 3 秒；状态机阻止重入。已读文章增添星点，已读记录保存在本浏览器。
4. **路灯**：HTML 控件每帧跟随真实相机投影；hover 修改独立灯光与局部环境；预览显示在控件旁上方，不盖住点击区域。分类切换同时调整场景和正确的文章列表。
5. **阅读**：按参考图第 07 格单独实现阅读状态：场景向上收成横向全景，正文从文章触发位置揭开为下方通栏区域。正文居左，右侧目录随滚动保持可用并标记当前章节，顶栏显示实际阅读进度；手机改为可展开目录。分类仍使用第 06 格侧栏，两种容器分别挂载，单一 panel tween 可中断并取消旧关闭回调。场景横幅位移和镜头各由独立 GSAP tween 控制，关闭反向恢复；尺寸变化重新取景。正常 HTML 可选择文字，支持相邻文章和独立 URL；独立静态页面使用同样的横幅、正文和目录排版，无 JavaScript 也可阅读。请求可中止且有缓存；错误时提供独立文章入口。
6. **返回与历史**：打开时记录场景输入、页面 scrollY、分类、焦点和触发位置；关闭恢复。history state 记录路由和快照；popstate 使用当前事件处理器，避免动态效果偏好和闭包状态过期。直接访问分类查询参数也能恢复对应界面。

## 适配与降级

- 一次访问保持一个 Canvas。桌面 DPR 上限 1.3，130 个着色器粒子；不做昂贵的全屏后处理。
- 页面隐藏或场景离开视口时暂停持续渲染；阅读时按需渲染，过渡完成后背景基本静止。
- `prefers-reduced-motion` 关闭视差、滚动穿行和持续运动；面板与唤醒状态即时到位。键盘 Enter 可等效唤醒。
- WebGL 初始化或纹理加载异常由边界处理：显示原画，明确提示静态模式，保留分类、搜索与文章入口。
- 独立文章为 Astro 输出的 HTML，无 JavaScript 也能阅读。
- 中文字体和所有纹理本地托管；没有运行时 CDN 依赖。

## 当前差距

- 保留了已确认画面的颜色、细线、站体、人物和主体关系，但为滚动探索使用整屏场景，最近更新在第三阶段以场景内卡片呈现。窄屏有独立构图；并非参考分镜的逐像素复制。
- 景层有真实深度，但没有建筑背面、自由环绕镜头、人物骨骼行走或完整三维地形。插画网格局部轮廓仍可继续精修。
- 唤醒的波沿绘制的地表传播，不是物理光照模拟；星图是程序化节点，尚无独立课程知识图谱数据。
- 纹理约 8.5 MB，Three.js 相关分包大于 500 kB 的构建警告保留。尚未在实体手机或 Safari 上测量帧率，不承诺所有设备 60fps。
- 当前文章与个人资料是示例，没有发布到公网。
