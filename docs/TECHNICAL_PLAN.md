# 异星日志：当前实现

更新：2026-11-06，在完整插画分镜切换的基础上恢复鼠标跟随和短转场。以下是实际接入的实现；更早的 2.5D 和人物动画文档是历史记录。

## 场景

Astro 页面挂载 React JournalApp，IllustratedWorld 显示原始远景与石碑近景。两幅图预先加载并 decode，使用互斥 visibility 保持唯一活动画面。单一 440ms GSAP tween 编排淡出、低透明度时换景、淡入，并有最多 8px 的纵向位移；反向输入直接 reverse，同一进度可连续退回。动画期间两个场景的热点均 inert，完成后恢复活动场景的操作。滚动进入近景阈值为 30%，退出为 25%；日志阶段 80% 返回远景，边界分离避免小幅滚轮抖动。

场景没有移动摄像机、分层地形或独立人物，也不加载 LayeredWorld。人物与环境是完整插画的一部分。手机分别为两张图采用固定裁切，没有随滚动缩放。依赖版本和 lockfile 保持不变。

## 反馈与控制来源

- SceneJourney 的唯一 ScrollTrigger 写入 scrollProgress，保留长滚动行程和场景内日志。
- IllustratedWorld 的 render 回调读取滚动及唤醒状态，设置唯一活动场景，更新 HTML/SVG 的颜色、描线进度、光点收拢、路径光、路灯光晕和星图。由 runtime.invalidate 调用，无 React 逐帧状态和持续渲染循环。
- `.frame-world` 只负责分类让位，`.frame-parallax` 只负责鼠标取景，`.scene-frame` 只负责转场透明度和小幅位移，避免多个动画写同一属性。GSAP quickTo 以 650ms power3.out 收敛到鼠标目标，水平最多 18px、垂直最多 10px；固定 1.032 倍留边覆盖四周，不随滚动缩放。标题 / 导航不在该容器内。离开、失焦时回中；悬停路灯或蓄力时暂停，阅读时回中并静止。触屏和减少动态模式不启用鼠标跟随。
- GSAP 的唯一蓄力 tween 控制约 1.1 秒长按，取消 tween 自然回退；松手、滚动、失焦、pointercancel 和隐藏窗口取消。
- GSAP 的唯一唤醒 timeline 控制碑文、切回远景、地面光波、三灯和星图。碑文亮起后一秒触发同一短转场回到完整远景，随后出现路径与灯光。约 4.85 秒完成；状态机防止重入。
- 唤醒后的远景保留至下一次明确导航或滚动；用户可再次进入近景查看点亮的石碑。
- 分类面板展开时完整插画轻微向左让位。阅读显示固定横幅与通栏正文；不再通过三维镜头后退取景。

## 阅读与导航

Markdown 构建为独立 HTML 和供 React 使用的 JSON。正文是正常 HTML，支持目录、文字选择、阅读进度和相邻文章。请求可以中止且有缓存；失败提供独立文章链接。

单一面板 GSAP tween 可中断与反向收回。打开前记录 scrollY、分类、触发点和焦点；关闭后恢复。history state 与 popstate 驱动相同导航函数，保留浏览器前进/后退、搜索、归档、关于。分类使用侧边纸张，正文使用全宽阅读布局。

## 适配与边界

- 无 WebGL 设备也有相同场景功能；没有 shader 编译步骤。
- 减少动态效果关闭鼠标跟随、场景和面板过渡与演出时长，明确的场景切换仍可用；Enter 等效触发唤醒。
- 近景资源加载失败时保留远景与文章入口并提示静态模式。
- 当前是静态插画分镜切换，加上局部反馈，并非连续空间探索。灯光和粒子反馈是 SVG / CSS，不是物理光照。
- 原图已有浅色路灯和星点，唤醒增强亮度与路径。手机测试为浏览器模拟；实体设备与 Safari 未实测。
