## 复查方式

先运行 `npm run dev`，打开 http://127.0.0.1:4321/ 。

1. 左右移动指针，再上下滚轮，观察前后景相对位置。
2. 按住石碑不到一秒松开，再长按约一秒，观看完整演出。刷新可重新体验。
3. 悬停任一灯旁标签，点击分类与文章，试目录、返回、浏览器后退与前进。
4. 缩到手机宽度，用底部入口分类与唤醒，再检查阅读。

自动复查脚本不改变应用依赖。当前 Windows 工作环境可使用已经安装的 Playwright：

```powershell
$env:PLAYWRIGHT_MODULE = 'C:/Users/ASUS/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright'
$env:BROWSER_EXECUTABLE = 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
node scripts/verify-browser.mjs
```

其他环境设置 `PLAYWRIGHT_MODULE` 为可用的 Playwright 模块路径，`BROWSER_EXECUTABLE` 为浏览器可执行文件；也可使用已安装 Playwright 的默认 Chromium。`PREVIEW_URL` 可以指定另一个本地预览地址。脚本会重新生成截图和 JSON。

## 尚未覆盖/仍有差距

- 手机是浏览器触摸与视口模拟，未在实体 Android/iPhone 或 Safari 上验收，也没有作出 60fps 保证。
- 当前约 8.53 MB 的四张 PNG 纹理及大体积 WebGL 分包仍有压缩空间；本地顺畅不能等同弱网加载速度。
- 使用有限视角的 2.5D 网格和补画底图；没有自由环绕、物体背面、人物行走。局部轮廓可以继续精修，未声称像素级复刻原视频。
- 文章和个人资料仍是示例；网站只在本地运行，没有公网部署。
