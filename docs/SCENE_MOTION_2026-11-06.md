# 完整插画的鼠标跟随与转场

目标：保留完整插画与分镜切换，恢复鼠标跟随和可中断的过渡，不重新接入拆图地形、行走人物或穿行镜头。

## 验证清单

- 鼠标向两侧移动：插画有可观察到的轻微平移，带阻尼；标题和导航位置不变。停下后收敛，离开窗口回中。
- 场景边界：可观察到淡出 / 淡入与少量纵向位移；不长时间叠加两个场景，不停在半透明状态。
- 过渡中反向滚动：从已有进度反向；快速反复输入不积累时间线、不闪回错误场景。
- 悬停分类与按住石碑：画面暂停追随，控件可点击；预览跟随灯的位置，不挡住灯。
- 阅读与返回：保留当前场景、滚动和分类；阅读期间背景回中并静止。
- 手机不受触摸滑动误触发鼠标视差；场景转场仍有效；390 / 320 下无横向溢出。
- 系统减少动态：无视差和转场位移，仍可切换场景、唤醒和阅读。
- 回归：蓄力取消 / 失焦 / 重试、唤醒、文章、历史、搜索、归档、关于；类型检查、测试和构建。

## 实现与边界

- 整幅插画随鼠标平移：水平 ±18px，垂直 ±10px，650ms power3.out 收敛。固定 1.032 倍留边避免露底；这属于完整画面的取景移动，不是物体之间的三维视差。
- 唯一 440ms GSAP tween：远景淡出至 12% → 换到近景 → 近景淡入；最多 8px 纵向位移。反向直接 reverse，不排队、不创建延迟换景回调。隐藏页面和减少动态模式直接落到目标状态。
- 悬停灯和蓄力时冻结鼠标偏移，预览跟随实际灯位置；阅读回中。位移、分类让位、场景转场分别作用于独立容器。useGSAP 清理所有 tween 和监听器，不使用 React 逐帧 setState。
- 人物是原画的一部分；仍然没有独立行走、骨骼动画和三维自由镜头。

## 已验证

`scripts/verify-scene-motion.mjs` 的 8 组检查通过，实际运行录像为 `output/playwright/scene-motion/scene-motion-actual.webm`。逐帧采样验证过渡存在中间透明度、只有一幅主场景可见，中途反向未先完成旧目的地。鼠标两端相差约 31px，标题 / 导航不移动；四角极限覆盖视口，停止后收敛。

`scripts/verify-browser.mjs` 的 21 组功能回归、类型检查、5 项状态机测试和静态构建通过。具体结果与真实截图见 QA.md 最新记录。手机为浏览器模拟。
