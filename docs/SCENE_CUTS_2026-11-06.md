# 完整插画场景切换 · 2026-11-06

用户明确要求回到最初直接切换场景的方式。当前首页用保留的完整远景 observatory-world.webp 和完整近景 monolith-encounter.webp；撤下活动页面中的透视穿行、拆分地形和人物行走。旧实验代码和资产留存，未删除用户素材。

## 本轮验收清单

- 首屏对照原画：完整人物、植物、山崖、路径和建筑；没有贴片接缝、重复地面。
- 远景 → 近景 → 远景：原生滚动/阶段按钮，切换前图片完成 decode；任一时刻只显示一幅主场景，停止时没有叠影。边界有进入/退出不同阈值，轻微滚轮抖动不会反复切换。
- 长按：圆环、碑文描线、光点收拢；提前松手、失焦和滚动取消；再次长按可以完成。唤醒后切回全景，路径、三盏灯、星图按统一时间线响应。
- 分类预览与点击；HTML 阅读、目录、关闭、分类和滚动恢复；浏览器前进/后退；搜索、归档、关于。
- 手机 390/320：不同场景分别采用固定裁切，没有滚动缩放；点按入口可达，没有横向溢出；正文仍为通栏布局。
- 减少动态：无穿行或连续场景运动；明确场景切换和键盘唤醒仍可用。禁用 WebGL 时所有现有功能仍正常，因为当前方案没有 Canvas 依赖。
- 非正常操作：反复跨越切换边界；切换途中立即反向；蓄力时滚动；关闭面板中重新打开；近景阅读并返回。

## 当前实现边界

这是完整插画之间的直接切换，**不是连续三维探索**。人物保留在画中，不再播放行走/骨骼动画。近景和远景构图各自固定，没有模拟中间视角。保留原有文章与阅读/历史逻辑；GSAP 仍统一控制蓄力、唤醒和面板动画，SVG 与 HTML 显示反馈。

参考图片本身已有浅色路灯和星点；唤醒增加路径光带、路灯光晕与星图亮度，未改画原始插画。两幅图有绘制视角差异，切换是有意的分镜切换。

具体运行结果及截图见 QA.md 最新记录。
